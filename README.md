# RIFT Artillery — 0.4.0

Пошаговая артиллерия для **Android и Windows / Unity**. 12 больших разрушаемых карт, 120 видов оружия и инструментов, семь рас, четыре босса и 16 музыкальных тем. Дуэль с ИИ, игра вдвоём на одном устройстве, канатная гонка. Русский интерфейс, офлайн, без рекламы и доната; магазин работает за материалы из боёв.

**[Android APK](dist/RIFT-Artillery-0.4.0.apk)** · **[Windows ZIP](dist/RIFT-Artillery-Windows-0.4.0.zip)** · [Android AAB](dist/RIFT-Artillery-0.4.0.aab) · [Unity-проект](unity) · [Каталог](docs/CONTENT.md) · [Проверки](docs/QA-0.4.0.md)

## Магазин и склад

Кнопка **«Магазин»** находится в главном меню Android и Windows. В магазине 14 наборов боеприпасов и снабжения и пять покупаемых аур. Цена, состав и количество на складе видны перед покупкой. Начальный баланс — 150 материалов. Победа приносит 60, победа над боссом — 180, поражение — 20, ничья — 30. Кузница использует тот же кошелёк.

![Магазин боеприпасов Android](docs/screenshots/v040-android-13-shop.png)

Каждый новый бой расходует **по одному набору каждого купленного типа**, добавляя указанные боеприпасы каждому бойцу игрока. Склад вмещает до девяти наборов одного типа. В дуэли вдвоём бонус получают оба отряда. В канатной гонке наборы не расходуются. Продолжение сохранённой партии тоже не расходует склад. Автоприменение можно выключить в магазине.

Ауры покупаются один раз, свободно переключаются и меняют цвет кольца под бойцами. Они не усиливают урон или здоровье. Покупки, склад, выбранная аура и выключатель наборов сохраняются локально; реальные деньги и интернет не нужны.

## Управление и исправления 0.3.1

- **Свободный проход через бойцов:** союзники и противники больше не перекрывают путь при ходьбе и не сдвигаются за персонажем. Можно остановиться рядом или пройти обратно без прыжка.
- **Управление Windows:** A / D и стрелки ← / →, клавиши с русской раскладкой, прицеливание мышью или ↑ / ↓, сила колесом или + / −. Открытые окна блокируют управление под собой.
- **Звук Windows:** восстановлен вывод музыки через AudioListener; в окне музыки есть громкость и выключатель. Проверяется сигнал на выходе микшера.
- **Полный экран:** F11, Alt+Enter или кнопка в главном меню и на паузе. Повторное нажатие возвращает оконный режим.

## Управление боем

- **Ходьба не таскает соседнего бойца.** Персонажи проходят друг через друга у земли. Столкновения с рельефом, отбрасывание взрывами и возможность встать сверху на другого бойца сохранены.
- **Новый прицел:** крупная панель с длинными ползунками, шагом 1° и 5°, разворотом и настройкой силы. Касание поля задаёт направление; дальнейшее движение пальца по горизонтали точно меняет угол, по вертикали — силу. Выстрел выполняется отдельно.
- **Телепорт и аптечка сохраняют ход и основную атаку.** Расходуется только запас предмета, время не пополняется. Недопустимая точка и ненужное лечение не тратят предмет.
- На ход даётся **59 секунд**, после атаки — три секунды на отход. Одна бесплатная смена союзника до атаки сохраняет время. Арсенал и точный прицел приостанавливают бой.

## Сборка из исходников

JDK 17, Android SDK 35 / Build Tools 34.0.0. Для Windows — Unity 6000.0.77f1 с Windows Build Support. Gradle Wrapper включён.

```powershell
. .\tools\Prepare-BuildEnvironment.ps1
.\gradlew.bat :core:test :desktop-core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
.\tools\Test-Android.ps1 -Adb "$env:ANDROID_HOME\platform-tools\adb.exe" -Serial emulator-5558
.\tools\Build-Release.ps1
.\tools\Build-Unity.ps1 -Package
```

Подготовка окружения создаёт локальный агент совместимости Java с Windows, где недоступен AF_UNIX loopback. Он используется только для сборки, не входит в игру и хранится в игнорируемой `.tmp`.

Ключ Android и защищённый Windows-пароль остаются в локальной `.private`. Для независимого проекта новый ключ создаётся `Build-Release.ps1 -CreateLocalKey`; для обновления приложения нужен прежний ключ. Ключи и пароли не публикуются.

`core` — общая симуляция; `app` — Android Canvas; `desktop-core` — локальный движок Unity; `unity` — отдельный проект C#. [Атласы](docs/ART_ASSETS.md), [план развития](docs/PRODUCTION_PLAN.md).

Офлайн-выпуск: сетевые матчи, серверные аккаунты, онлайн-кооператив, рейтинги и редактор карт не реализованы; публикация в магазине не выполнена. Численное совпадение всех правил с Wormix не заявляется.
