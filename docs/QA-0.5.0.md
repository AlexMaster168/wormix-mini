Ядро проверяет все 20 новых предметов и каталог из 140 уникальных названий. Для кассет проверяются шесть и двенадцать отдельных зарядов; для оружия — три луча, 24 иглы, шесть дробин, два рельсовых импульса и три вертикальных луча спутника. Существующие сценарии исполнения всех предметов, физики, урона, сохранений и магазина сохранены.

Для дропа проверены задержка перед снижением, приземление на рельеф, возобновление падения после разрушения опоры, четыре одновременно существующих ящика, запрет подбора в воздухе, одноразовый подбор, пределы HP, брони и боеприпасов, сохранение редкого содержимого и траектории после загрузки. Подготовка доставки не дублируется при повторной обработке третьего хода. Разрушенный и утонувший груз удаляется; в гонке доставки нет. Неудачный вызов при лимите сохраняет заряд маяка.

Редкий груз выбирает оружие только когда не требуется завершить второй выстрел дробовика. Эта ситуация покрыта отдельной проверкой. Подбор боеприпасов в середине такой атаки не позволяет обойти её ограничение.

Android вызывает медицинского дрона через арсенал, проверяет сохранение атаки, заморозку задержки на паузе, начало падения и подбор медицинского груза. Позиция для проверки подбора задаётся на настоящей поверхности рельефа, затем используется видимая кнопка взаимодействия. Проверки ждут отрисовки кнопки перед нажатием: ранний планшетный прогон выявил обращение к списку элементов предыдущего кадра. Неуспешный прогон в итог не засчитан. Шесть новых атак отдельно проверены через сенсорное управление.

Windows исполняет общий движок в собранном EXE: вызывает медицинский груз, проверяет задержку, фактическую посадку, сохранение её состояния и отказ от ненужного лечения без исчезновения ящика. Сохранены проверки мыши и клавиатурного обработчика, русской раскладки, полного экрана, музыки на выходе микшера и магазина. Это программные события внутри плеера; полный ручной прогон физических устройств ввода не заявляется.

Подписанное обновление 0.4.0 → 0.5.0 сохраняет доступную незавершённую партию в интерфейсе 0.5.0. Старые 120 позиций инвентаря читаются в прежнем порядке; новые 20 получают стартовый запас. Формат партии v4 не изменён: положение, HP, задержка, посадка и содержимое ящика хранятся в уже существующих полях устройства. Профиль магазина остаётся v1 с теми же 19 предложениями.

Финальные изображения Android сняты обычными действиями в подписанном выпуске; Windows — из окончательного плеера после тестов. [Манифест](screenshots/manifest-v050.json) связывает их с бинарными файлами и временем проверок. Снимки неизменившегося магазина и старых карт в README оставлены из предыдущих выпусков и обозначены отдельно.
