# Графика версии 0.2

Персонажи хранятся в прозрачных PNG-атласах. Интерфейс, окружение, земля и эффекты рисуются Android Canvas. Изображения из Wormix не используются.

## Герои

Файл: [heroes-atlas.png](../app/src/main/assets/heroes-atlas.png). Прозрачный атлас: семь колонок, две строки; спокойная стойка и шаг. Порядок: драконид, киборг, мутант, демон, наёмник, нежить, фантом. Нарезка и отражение выполняются при отрисовке.

Бойцы ориентированы вправо; для противоположной команды применяется отражение. Равные ячейки и выровненные ступни позволяют переключать позы без смещения персонажа. Оружие и конечности располагаются внутри своей ячейки.

## Боссы

Файл: [bosses-atlas.png](../app/src/main/assets/bosses-atlas.png). Прозрачный атлас четырёх боссов: Инферно, Алхимик, Фафнир, Генерал.

Одна строка из четырёх равных ячеек, персонажи ориентированы влево. Инферно использует огненный меч, Алхимик — механический глайдер с химическими баками, Фафнир — крылья и длинный хвост, Генерал — тяжёлую броню и шестиствольное оружие. Для боссов используются увеличенные область отрисовки и зона попаданий.
